## How to plot Color CNN genomic scan results

### Prerequisites
- A predictions CSV file generated by `color_CNN_inference.py`. See the [inference README](../inference_color_CNN/using_inference_color_CNN.md).
- Optionally, a positions file mapping each image index to its genomic center position in base pairs.

---

### 1. Copy the plotting script to your working directory
```bash
cp /u/project/ngarud/Garud_lab/Brendan/Utils/plot_inference_results/plot_inference_results.py .
```

### 2. Run the plot
```bash
python plot_inference_results.py <predictions_csv> [options]
```

| Argument         | Required | Default           | Description                                                              |
|------------------|----------|-------------------|--------------------------------------------------------------------------|
| `predictions`    | Yes      | —                 | Path to predictions CSV from `color_CNN_inference.py`                    |
| `--positions`    | No       | —                 | CSV/TSV mapping `Image_Index` to `Center` (genomic position in BP)       |
| `--bin_size`     | No       | 3                 | Number of consecutive windows to average together                        |
| `--title`        | No       | `Genomic Scan`    | Plot title                                                               |
| `--output`       | No       | `genomic_scan.png`| Output plot filename                                                     |
| `--dpi`          | No       | 300               | Plot resolution                                                          |

### Examples
```bash
# Basic: plot using window index as x-axis
python plot_inference_results.py predictions.txt

# With genomic positions and custom title
python plot_inference_results.py \
    GHIST_predictions.txt \
    --positions GHIST_window_positions.csv \
    --title "R. bromii Genomic Scan" \
    --output r_bromii_scan.png

# Larger bin size for a smoother plot
python plot_inference_results.py \
    predictions.txt \
    --positions positions.csv \
    --bin_size 5 \
    --title "E. coli Genomic Scan"
```

### 3. Positions file format
The positions file should be a CSV or TSV with at least two columns:
```
Image_Index,Center
0,15234
1,18567
2,21890
...
```

`Center` is the midpoint (in base pairs) of the genomic window corresponding to each image. If no positions file is provided, `Image_Index` is used as the x-axis.

### 4. How the plot works
- The y-axis is `-log10(P_Neutral)`: higher values indicate stronger evidence of a sweep.
- Each point is colored by the class with the highest predicted probability: grey for neutral, red for hard sweep, and sky blue for soft sweep.
- Consecutive windows are averaged together based on `--bin_size` to smooth noise. A bin size of 1 shows raw per-window predictions.

### 5. Expected input format
The predictions CSV must have these columns (as output by `color_CNN_inference.py`):

| Column           | Description                          |
|------------------|--------------------------------------|
| `Image_Index`    | Zero-based index of the window       |
| `Predicted_Label`| Winning class label                  |
| `Confidence`     | Probability of the winning class     |
| `P_Neutral`      | Predicted probability for Neutral    |
| `P_Hard`         | Predicted probability for Hard sweep |
| `P_Soft`         | Predicted probability for Soft sweep |
